#  🌦️ Weather Dashboard App

A simple and responsive weather dashboard web application built using Django and Python.  
The application fetches real-time weather data using the OpenWeather API and dynamically displays city images using the Unsplash API.

---

## Features

- Search weather by city name
- Real-time temperature updates
- Wind speed and humidity display
- Weather condition information
- Dynamic city background/image
- Responsive user interface
- SQLite database integration
- API integration using Python requests

---

## 🛠️ Tech Stack

- Python
- Django
- SQLite3
- HTML, CSS, Bootstrap
- OpenWeather API
- Unsplash API

---

## 🔗 APIs Used

### OpenWeather API
Used to fetch live weather information.

🔗 https://openweathermap.org/api

### Unsplash API
Used to fetch city-related images dynamically.

🔗 https://unsplash.com/developers
